# Contributing

Thanks for considering a contribution.

## Good contributions

- Accessibility improvements
- Responsive layout fixes
- Performance improvements
- Documentation improvements
- Small visual or semantic HTML fixes

## Before opening a pull request

1. Keep the project dependency-free unless there is a strong reason not to.
2. Do not add credentials, private customer information or analytics secrets.
3. Test the page locally in a modern desktop and mobile browser.
4. Keep changes focused and explain what they improve.

## Pull requests

Include a short description of the problem and the change. Screenshots are welcome for visual changes.
